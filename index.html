Concatenate Quake III Arena demos into one file

Concatenate (merge, combine) Quake 3 demos: pick the parts of a recording (.dm_68 and the like), put them in playback order, get one demo. Parts of the same game recorded back to back are joined seamlessly; anything else is joined with a level reload in between. Nothing is uploaded. This might be useful if you did `\stoprecord` with `\set cl_autoRecordDemo 1`.
